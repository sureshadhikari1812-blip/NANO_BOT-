# 🤖 NANO_BOT

A Telegram bot for downloading media using `yt-dlp`.

## ✨ Features

- Telegram bot interface
- Media downloading
- `yt-dlp` support
- Easy Termux setup
- Token stored separately from source code

## 📋 Requirements

- Termux
- Python 3
- Git
- Telegram Bot Token
